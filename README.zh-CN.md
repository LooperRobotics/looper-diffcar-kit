# Looper 差速小车套件

[English](README.md) | 中文

[![观看 Looper 小车视频](https://img.youtube.com/vi/pFE__Sl7H8M/maxresdefault.jpg)](https://www.bilibili.com/video/BV1Gepv6jE2D/)

视频：[B 站](https://www.bilibili.com/video/BV1Gepv6jE2D/) · [YouTube](https://www.youtube.com/watch?v=pFE__Sl7H8M)

用一台 Looper 相机，加上 ESP32、电机驱动板、两个电机和几个 3D 打印件，搭一台能建图、自主导航的差速小车。

- 建图、定位、避障、网页控制都在 Looper 里运行，**需要预装差速车系统的 Looper**，购买时请说明。
- 本仓库提供小车这一侧需要的东西：物料清单、接线方法、ESP32 固件。

| 目录 | 内容 |
|---|---|
| `firmware/esp32/` | ESP32 固件：驱动电机、读轮子编码器、测电池电压、点状态灯，同时作为整车的 WiFi 网卡 |
| `README.zh-CN.md` | 本文：物料、接线、刷固件、第一次使用（英文版是 `README.md`） |

3D 打印件的模型文件和组装照片还在整理，之后会补到 `3d/` 目录。

## 2. 接线

方向约定：车头朝前，万向轮在车头，「左」「右」指从车尾往前看的左右。

### 2.1 供电

电池（12 V）同时接两处，两路并联：

- Looper 的 GH1.25 8 针口：①12V 输入、②GND；
- 驱动板的电源输入。

驱动板稳压出 5 V 给 ESP32（见 2.3 的 5V、GND 两根线）。

### 2.2 Looper ↔ ESP32

**USB**：用 C-to-C 线把 Looper 的 Type-C 口接到 ESP32 的**原生 USB 口**（芯片自带的那个口，不经过串口芯片）。ESP32 会作为网卡出现在 Looper 上，车的 WiFi 都走这根线。

**串口**：GH1.25 8 针口的针序（从底部看、从左往右）：

| 针 | 信号 | 接到 |
|---|---|---|
| ① | 12V 输入 | 电池正极 |
| ② | GND | 电池负极 |
| ③ | 外部触发 | 不接 |
| ④ | UART_RX（Looper 收） | ESP32 **GPIO41**（ESP32 发） |
| ⑤ | UART_TX（Looper 发） | ESP32 **GPIO40**（ESP32 收） |
| ⑥ | GND | ESP32 GND（建议接上，抗电机干扰） |
| ⑦ | 外部触发 | 不接 |
| ⑧ | 秒脉冲输入 | 不接 |

串口是交叉接的：Looper 的收接 ESP32 的发，Looper 的发接 ESP32 的收。

### 2.3 ESP32 ↔ 驱动板

ESP32 开发板左排排针，从 RST 下面第一个孔往下数：

| 左排第几个 | ESP32 引脚 | 驱动板 | 说明 |
|---|---|---|---|
| 1 | GPIO4 | E2B | 左轮编码器 B |
| 2 | GPIO5 | E2A | 左轮编码器 A |
| 3 | GPIO6 | E1B | 右轮编码器 B |
| 4 | GPIO7 | E1A | 右轮编码器 A |
| 5 | GPIO15 | PWMB | 左轮 |
| 6 | GPIO16 | BIN2 | 左轮 |
| 7 | GPIO17 | BIN1 | 左轮 |
| 8–10 | GPIO18、GPIO8、GPIO3 | 不接 | |
| 11 | GPIO46 | STBY | 驱动使能 |
| 12 | GPIO9 | 不接 | |
| 13 | GPIO10 | ADC | 电池电压检测 |
| 14 | GPIO11 | AIN1 | 右轮 |
| 15 | GPIO12 | AIN2 | 右轮 |
| 16 | GPIO13 | PWMA | 右轮 |
| 倒数第 2 | 5V | 5V | ESP32 由驱动板供电 |
| 最后 | GND | GND | 必须共地 |

### 2.4 电机

- 左电机接驱动板 **B 通道**，它的编码器对应 E2A / E2B；
- 右电机接驱动板 **A 通道**，它的编码器对应 E1A / E1B。

左右接反，车会原地打转或前后颠倒。

## 3. 刷 ESP32 固件

建议装车前先刷好。

1. 安装 [PlatformIO](https://platformio.org/install)（VS Code 插件或命令行版都可以）。
2. 用 USB 线把 ESP32 的**串口那个 Type-C 口**（经 CH343 串口芯片，通常标 COM 或 UART）接到电脑。
3. 编译并烧录：

   ```bash
   cd firmware/esp32
   pio run -t upload
   ```

   电脑上插着多个串口设备时，用 `--upload-port` 指定端口，例如 Linux 上 `--upload-port /dev/ttyACM0`、Windows 上 `--upload-port COM5`。

以后升级固件也是这样操作，标定数据保存在 ESP32 里，升级不会丢。

## 4. 第一次上电：标定编码器方向

新刷的 ESP32 不知道两个编码器的正负方向，在标定之前，车不会按速度指令走。这一步只需要做一次。

1. **把车架空，让两个驱动轮离地**，标定时轮子会转。
2. 接上电池，ESP32 的串口 Type-C 口接电脑。
3. 打开串口终端：`pio device monitor`（波特率 115200）。
4. 输入 `j` 回车。两个轮子各正转 1 秒，状态灯变黄。看到「标定结束，闭环已解锁」后，输入 `w` 回车保存。

如果提示某个轮子「几乎没转」，检查这个电机的供电线和编码器线。输入 `?` 回车可以查看当前状态，输入 `P` 回车可以打印接线表。

## 5. 连上小车

### 5.1 先连车的热点

上电几秒后，车会开出自己的 WiFi 热点（网页要等 Looper 启动完，约 1 分钟）：

- 名字：`Looper-XXXX`（XXXX 是每台车不同的 4 位编号）
- 默认密码：`looper1234`

手机或电脑连上这个热点后，浏览器打开 **http://192.168.4.1:8000**，就能看到小车的网页。

建议在网页 **Device** 页把热点密码改掉（Change name / password）。所有车出厂时的默认密码都一样。

### 5.2 让车连你的 WiFi（可选）

想让车和电脑在同一个局域网里：

1. 在 **Device** 页的网络设置里点 **Add network**，填你的 WiFi 名字和密码。可以存多个，按顺序尝试。
2. 把 **Connection mode** 从 **Car hotspot** 切到 **Wi-Fi router**。网页会先试连一次，并告诉你切过去后车的新地址（`http://<地址>:8000`）。
3. 手机或电脑回到同一个 WiFi，打开那个地址。在同一个局域网里，电脑上一般也可以用 **http://looper.local:8000**（安卓手机不支持这种名字）。

找不到车的时候：

- 切到路由器后 5 分钟内没有人从新网络打开网页，车会自动回到自己的热点；
- 路由器模式下 90 秒连不上任何已保存的 WiFi，车也会开出热点；
- 还是找不到：上电后 10 秒内断电，连做 2 次，第 3 次上电时车会强制回到热点模式。

## 6. 状态灯

ESP32 板上的彩色灯：

| 灯 | 含义 |
|---|---|
| 蓝色闪一下 | 刚上电 |
| 绿色常亮 | 正常 |
| 黄色 | 正在标定、自检或升级固件 |
| 红色慢闪 | 行驶中 2 秒没收到指令，已自动停车 |
| 红色快闪 | 轮子堵转，电机已停 |
| 紫色闪 | 电池电压低（低于 9.5 V），请充电 |
| 橙色慢闪 | 5 秒没收到 Looper 的消息：Looper 还在启动、串口线没接好，或者 Looper 上的程序没在运行 |
| 青色慢闪 | 正在看车的网页异常断开了（断网，或手机锁屏）。那台设备重新打开网页后熄灭 |
| 白色 | 固件不会显示这个颜色，说明灯的信号线受到了电机干扰 |

## 7. 使用注意

- 电池满电约 12.6 V，11 V 左右都属正常。低于 9.5 V 时，车会停车并闪紫灯。
- **运行时请拔掉充电器**：边充电边跑，可能干扰串口、让 ESP32 反复重启。
- 电量低时急加速、急转弯，可能让整车瞬间掉电重启，请及时充电。
